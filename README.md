# TAHQĪQ · تحقيق

**منصّة ويب متكاملة للتحقق من التلاوة القرآنية** — تغطية كاملة للمصحف الشريف (114 سورة · 6236 آية بالتشكيل العثماني)، مع تشغيل نموذج **Whisper** مباشرة داخل المتصفح عبر **ONNX Runtime Web (WASM)**، ومحرِّك **تراصف قسري (Forced Alignment)** بتقنية **التفكيك المدرَّس (Teacher Forcing)** مع استخراج **مصفوفة الانتباه المتقاطع (Cross-Attention)** لتوقيت كل كلمة، وتقييم مبدئي لأزمنة **المدود والغنن** حسب عتبة المطابقة `τ`.

> 🔒 **الخصوصية:** كل المعالجة الصوتية تتم على جهازك (On-Device). لا يُرفع الصوت لأي خادم إطلاقًا.

---

## ▶ التشغيل

```bash
npm install        # تثبيت الاعتماديات
npm run data       # (اختياري) إعادة توليد النسخة المحلية للمصحف من AlQuran Cloud
npm run dev        # التطوير على http://localhost:3000
npm run build && npm run start   # الإنتاج
```

### أول استخدام
1. اختر السورة والآية (أو «السورة كاملة»).
2. اضغط زر التسجيل وسجّل تلاوتك — أو ارفع ملفًا صوتيًا — أو جرّب **العرض التجريبي (محاكاة)** لمعاينة المحرّك كاملًا دون ميكروفون.
3. عند أول تحليل حقيقي سيُنزَّل نموذج Whisper تلقائيًا (~43MB للـ tiny) ويُخزَّن مؤقتًا في المتصفح (Cache API) فيكمله التحميل التالي.

## 🧠 محرك التراصف القسري (How it works)

### 1) سلسلة المحرّكات مع النسخ الاحتياطية التلقائية

| # | المحرّك | الوصف |
|---|---------|-------|
| 1 | **Whisper + Cross-Attention** | التفكيك المدرَّس: يُجبَر مدخل المُفكِّك على توكنز الآية المستهدَفة، ثم تُستخرَج مصفوفة الانتباه المتقاطع (توكن → إطار صوتي 40ms) → نقطة ارتكاز كل كلمة + حدّة الصف (Confidence) |
| 2 | **Whisper + التوقيت الزمني** | إذا تعذّرت مصفوفة الانتباه: تُطابَق كلمات النسخة (لغة عربية مُجبَرة `language:'ar'`) مع الكلمات المستهدَفة (LCS) وتُؤخَذ أزمنة كل كلمة من توكنز التوقيت التي يُخرجها Whisper نفسه |
| 3 | **Whisper + Energy-DTW** | إذا تعذّر كلا المسارين: نسخة + توزيع إطار-بطاقة وفق أزمنة التشكيل مع التقاط قمم الطاقة |
| 4 | **Energy-DTW (احتياطي)** | يعمل دائمًا دون أي نموذج: VAD على غلاف الطاقة (إطارات 40ms) + أزمنة نموذجية من التشكيل + توزيع متسلسل يلتقط القمم |

التفكيك الصوتي مُجبَر على العربية (`language: 'ar'`, `condition_on_previous_text: false`) حتى لا تنطق النماذج الصغيرة بالإنجليزية (وهمٌ لغوي) على العينات القصيرة، والمعالجة مقسَّمة إلى مقاطع 28 ثانية متسامحة: فشل مقطع واحد لا يسقط التحليل كله.

عند أي فشل (بلا شبكة لتنزيل النموذج، عطل WASM/ONNX، صلاحيات…) ينقل المنسِّق التحليل تلقائيًا إلى المستوى التالي **دون انقطاع**، ويظهر المحرّك الفعلي في لوحة النتائج.

### 2) التقاط الحدود الدقيقة (VAD)
بعد استخراج نقطة ارتكاز كل كلمة (من أي محرّك)، تُحسَب حدود البداية/النهاية الفعليّة بتتبّع الإطار المُتكلَّم حول النقطة بعتبة محلية لكل كلمة (مع تسامح اهتزاز إطار واحد داخل الكلمة)، ثم تُفرض الأحادية (لا تداخل).

### 3) محرّك قواعد التجويد (بالسياق الكامل للكلمة التالية)
لكل كلمة — ومعرفتها للكلمة التي تليها — تُكتشف الأحكام ويُستنتج **زمنها النموذجي**:
- المقاطع (فتحة/كسرة/ضمّة/تنوين + سُكون الختم)
- **المَدود**: طبيعي (+350ms) · **واجب متصل** (قالَ/سَأَلَ: حركة+همزة داخل الكلمة) · **واجب منفصل** (كلمة تنتهي بمدّ + الكلمة التالية تفتح على همزة) · **تعويضي** (سكون ختمي + فتحة في الكلمة التالية) — الوجوبيان والتعويضي +650ms
- **الغُنَن**: مدّية (ن/م بشدّة +300ms) · **إخفاء** (نون ساكنة/تنوين قبل 15 حرفًا +300ms) · **إدغام لغوي** بغُنّة (ي/ر/ل/ن) أو بلا غُنّة · **إدغام شفويّ** (ميم ختمية قبل ب/م/ل/ن/ي/ر) · **إظهار حلقي** (أ/ه/ع/ح/غ/خ — بلا غُنّة)
- **قَلْقَلَة**: ق/ط/ب/ج/د ساكنة أو مشدَّدة في أي موقع (+40ms)
- **لاَم التعريف**: شمسيّة (قبل 14 حرف شمسيًا) أو قَمَريّة — تُعرض كشارة

الأحكام تظهر شارات ملوّنة في جدول النتائج (بحدّ أقصى 3 لكل كلمة + عدّاد للبقية).

ثم تُقارن المدة المقاسة بالنموذجية بنافذة سماحية تعتمد على `τ`:
`tolerance = 0.60 − 0.45·τ` → τ=0 (±60% مُيسَّر) … τ=1 (±15% تجويد صارم)

الحالات: `مُتقَن ✓ / متوافق / قصير ↓ (مد ناقص) / طويل ↑ (إفراط) / غير مسموع`

**تنبيه المخالفات:** أثناء التشغيل المتزامن، عند مرور رأس التوقيت على كلمة مخالفة (قصير/طويل/غير مسموع) يهتز الجهاز (Vibration API) ويصدر نغمة تحذيرية — قابل للإيقاف من زر 📳 في شريط التشغيل.

**الدرجة الكلية** = 50% متوسط الثقة + 50% متوسط مطابقة التجويد.

### 4) حدود واقعية (معلنة بشفافية)
- نافذة Whisper 28 ثانية: يُعالَج الصوت في مقاطع (حتى 4) للنسخ.
- مسار الانتباه المتقاطع يعمل للنصوص القصيرة (≤60 كلمة و ≤31 ثانية) لتفادي تضخّم المصفوفة؛ لما يتجاوز ذلك يُستخدَّم المسار الطرائقي.
- الأداة **مساعدة للتمرن** وليست حكمًا إيمولوجيًا ولا بديلًا عن المُجوِّد.

## 📡 بيانات القرآن

- **الحي:** `GET /api/quran/surahs` و `GET /api/quran/surah/:id` → بروكسي لنسخة `ar.quran-uthmani` من [AlQuran Cloud](https://alquran.cloud) (قائمة + 114 سورة بالتشكيل الكامل).
- **الاحتياطي:** النسخة المحلية `public/quran.json` (1.5MB، 114 سورة) تُخدَّم تلقائيًا عند غياب الشبكة — ويُعاد توليدها بـ `npm run data`.

## 🎛 لوحة التحكم (Alignment Model Settings)

- **حجم النموذج:** Whisper-tiny (~43MB) / Whisper-base (~80MB) — يُخزَّن مؤقتًا في Cache API.
- **معيار المطابقة τ:** شريط تمرير 0.0 → 1.0 (من المُيسَّر إلى التجويد الصارم) — يؤثر مباشرة على نافذة سماحية التصنيف.
- **حالة المُشغِّل:** نقطة حية (خمول/تحميل %/جاهز/فشل) + شريط تقدّم التنزيل + رسالة الفشل.

## 🖥 محيط التسجيل (Recitation Panel)

- زر بدء/إيقاف بنمض أحمر + **موجة صوتية حية** (AnalyserNode → Canvas).
- **رفع ملف صوتي** (أي صيغة يدعمها المتصفح → يُفكَّك ويُعاد عيّنته إلى 16kHz أحادي).
- **عرض تجريبي (محاكاة):** يولّد عينة 16kHz واقعية الحدود وفق أزمنة التشكيل (بأخطاء منتظمة) لاختبار كامل المعالِج دون ميكروفون — مفيد في البيئات المقيدة.
- **إعادة التحليل** بالـ τ/النموذج الحاليين دون إعادة التسجيل.

## 📊 شاشة نتائج التراصف (Alignment Console)

- موجة العيّنة مع رأس تقدّم + **تشغيل متزامن**: تُضاء بطاقة الكلمة الفعّالة في شريط النص وفي جدول النتائج مع تقدّم الصوت.
- ملخص: الدرجة الكلية، مطابقة النسخ (مع تظليل الكلمات غير المطابقة في Transcript)، المدة، المحرّك المستخدَم.
- جدول تفصيلي لكل كلمة: البداية/النهاية (ثوانٍ)، المدة (قياس/متوقع)، شريط الثقة، حالة القراءة، وأحكام التجويد المكتشفة (مد/غنّة).

## 📱 تطبيق الجوال (PWA) + التجاوب

- **قابل للتركيب:** `manifest.webmanifest` + أيقونات (192/512/maskable + apple-touch-icon) → من متصفح الجوال: قائمة ⋮ ← **"إضافة إلى الشاشة الرئيسية"**، فيفتح كتطبيق مستقل (display: standalone) بخلفية داكنة وشعاره الخاص.
- **يُعمل دون إنترنت (بعد أول زيارة):** Service Worker (`public/sw.js`) يخزّن واجهة التطبيق وبيانات المصحف المحلية (`/quran.json`)، مع استراتيجية network-first للـ API و cache-first للموارد الثابتة. نموذج Whisper يبقى معتمدًا على الشبكة (تُخزَّنه المتصفحات ذاتيًا عبر Cache API).
- **متجاوب كليًا:** الترويسة قابلة للطي على الشاشات الضيقة، شريط السور قابل للتمرير، جدول النتائج بتمرير أفقي — مُختبَر على عرض 360px فأعلى.

## ℹ ملاحظات تقنية

- **الاعتماديات:** Next.js 15 (App Router) · React 19 · Tailwind CSS 3 · Zustand 5 · @huggingface/transformers 3 (ONNX Runtime Web).
- `@huggingface/transformers` يُحمَّل كـ **lazy chunk** (≈0.5MB) فقط عند أول طلب نموذج — صفحة التحميل الأولى 120KB فقط.
- **تثبيت محرّك ONNX Runtime Web:** إصدارات transformers.js 3.x تخدم ملفات WASM من حزمة CDN الخاصة بها (وبعضها تبني -dev معيبة بخلل int64/BigInt يُسقط Whisper على متصفحات الجوال — "Cannot convert a BigInt value to a number"). لذلك يُثبَّت `wasmPaths` صراحةً على الإصدار المستقر `onnxruntime-web@1.20.1` (مع CDN احتياطي)، ويُثبَّت npm override على الإصدار نفسه لتوحيد الحزمة JS/WASM.
- ملفات WASM الخاصة بـ ONNX Runtime Web تُنزَّل من CDN عند التشغيل (تتطلب شبكة مرة واحدة)، وإلّا يُفعَّل الاحتياطي تلقائيًا.
- الخطوط: Amiri (نص المصحف) + Space Grotesk (العلامة) عبر Google Fonts مع بدائل نظام.
- توليد أيقونات التطبيق: `npm run icons` (SVG → PNG عبر sharp).
