# تَحَقُّق — تطبيق التدريب على تلاوة القرآن بالتجويد

**تَحَقُّق** تطبيق ويب عربي يساعدك على إتقان تلاوتك:

1. **اختر** الرواية (حفص عن عاصم أو ورش عن نافع)، ثم السورة والآية (أو السورة كاملة) —
   النصّ بالرسم العثماني والتشكيل الكامل.
2. **سجّل** تلاوتك بالميكروفون أو ارفع تسجيلًا صوتيًا من جهازك.
3. **اقرأ نتيجتك** لكل كلمة: حالتُها (مُتقَن / جيد / أقصر من المطلوب / أطول / لم يُسمع)،
   ودقةُ نطقها، وأحكامُ التجويد فيها مع شرحٍ مبسَّط لكل حكم عند تمرير المؤشر عليه.

> 🔒 **خصوصيتك أولًا:** صوتك يُعالَج كله **على جهازك** في المتصفح. لا يُرسَل الصوت ولا أي بيانات
> إلى أي خادم. وبعد أول تجهيز للسماع الذكي يعمل التطبيق **دون إنترنت** — بما في ذلك خطوطه:
> لا يُطلب أي خطٍّ من الشبكة (لا Google Fonts ولا غيرها)، بل تُستعمل خطوط الجهاز نفسها.

---

## كيف تبدأ

1. افتح التطبيق، ومن الشريط العلوي اختر سورة ثم آية.
2. من لوحة «إعدادات التقييم» اختر السرعة (٤٣ م.ب) أو الدقة الأعلى (٨٠ م.ب) واضغط
   «تجهيز السماع الذكي» — مرة واحدة فقط، ثم يعمل دون اتصال.
3. من لوحة «سجّل تلاوتك» اضغط زر الميكروفون واقرأ الآية بصوت واضح، ثم أوقف.
4. في لوحة «النتيجة» شغّل تسجيلك لتُضاء الكلمات مع صوتك: على الجوّال تظهر الكلمات **بطاقاتٍ**
   بلا تمرير أفقي، واضغط أي شارة حكم لتُفتح لك **شرحُها فورًا** (وتجمع «دليل الأحكام» كل ما ظهر
   في تلاوتك في مكان واحد).
5. جرّب زر «تجربة سريعة» إن أردت المعاينة دون ميكروفون.

**تلميح:** ارفع «صرامة التقييم» تدريجيًا كلما تحسّنت تلاوتك.

## ماذا يعرف التطبيق من أحكام التجويد؟

محرِّك الأحكام مبنيّ **على الرسم العثماني نفسه** (علامات المصحف: سكون ـۡ، مدَّة ۤ،
همز مبدَّل ـٰٓ، قلب ۢ، صلة ۥ/ۦ، ألف خنجرية ـٰ، والأصفار الصامتة ۟ ۠)، ويغطّي
تقسيمات **تحفة الأطفال** و**متن الجزريّة** على رواية **حفص عن عاصم**:

| الباب | الأحكام المكشوفة |
|---|---|
| **المدود** | طبيعي · واجب متصل · جائز منفصل · بدل · لازم (كلمي مُثقَّل · كلمي مُخفَّف · حرفي للفواتح) · لين · عارض للسكون · العِوَض (الوقف على التنوين) · صلة كبرى وصغرى (بالعلامتين ۥ ۦ وبالبنية) |
| **النون الساكنة والتنوين** | إظهار حلقي · إدغام بغنة (ينمو كاملًا بما فيه الياء والواو) · إدغام بغير غنة (ل/ر، ويحسب «مِنَ الْ» و«عَنِ الْ» المرسومتين مفتوحتي النون) · إقلاب (بالباء وبالعلامة ۢ وبالنون المقترنة بها داخل الكلمة وخارجها) · إخفاء (١٥ حرفًا) · وداخل الكلمة: إظهار (ٱلْأَنْهَار) وإخفاء (ٱلدُّنْيَا وبُنْيَان وقِنْوَان وصِنْوَان عند حفص) |
| **الميم الساكنة** | إخفاء شفوي (ٱلۡب) · إدغام متماثل صغير (ٱلۡم) · إظهار شفوي (الباقي) |
| **الغنن** | غُنّة مدِّية (نّ ومّ) · غنّة الإدغام · غنّة الإخفاء · غنّة الإقلاب · غنّة الإخفاء الشفوي |
| **الراءات** | مفخَّمة · مرقَّقة (مع حكم ما بعد الياء الساكنة وهمزة الوصل) · يجوز فيها الوجهان عند حفص (فِرْقٍ، مِصْرَۢ، خَيْرٌ…) |
| **اللام** | لام التعريف شمسية/قمرية · لام لفظ الجلالة تفخيمًا وترقيقًا (مع حكم ما قبلها وباءِ الجر وواوِ العطف) |
| **القلقلة** | كبرى عند الوقف · صغرى وسط الكلمة (سكون أصلي) |
| **عامّ** | حروف الاستعلاء (خصّ ضغطٍ قِظْ) تُعرَف وتُشار إلى تفخيمها |
| **أحكام الوقف** | تُشار إليها صراحةً في اسم الحكم: (عند الوقف) |

وتُفحص التغطية **على المصحف كاملًا** (٧٧٨٨١ كلمة): كل كلمته تُحلَّل في اختبار آلي
(`npm run test:rules`) بأكثر من ٩٠ حالة مأخوذة من آيات حقيقية (ٱلۡحَاۤقَّةُ، ٱلضَّاۤلِّينَ،
ءَاۤلۡـَٰنَ، بَنُوۤا۟، ٱلۡمَغۡضُوبِ، صِرَٰطَ…).

### الروايتان: حفص عن عاصم وورش عن نافع

بدّل الرواية من لوحة «الرواية والقارئ المرجعي»، فيُقيَّم نطقك على أصول روايتك، ويمكنك أن تسمع
الآية من قارئٍ متقنٍ بالرواية نفسها قبل أن تسجّل (وهو الخيار الوحيد الذي يحتاج إنترنت).

| الباب | حفص | ورش (من طريق الأزرق) |
|---|---|---|
| **مد البدل** | حركتان (٣٥٠ م.ث) | ثلاثة أوجه: حركتان أو أربع أو ستّ — والاعتماد في التقييم الوسط |
| **المتصل والمنفصل** | ٤–٥ حركات | ٦ حركات مشبعة |
| **الصلة الكبرى** | ٤–٥ | ٦ |
| **الهمز** | تحقيق الهمزة الساكنة | **إبدال الهمز الساكن** حرفَ مدّ (يَأْكُلُ ← يَاكُلُ، يُؤْمِنُ ← يُومِنُ) · **النَّقْل** (مِنْ آمَنَ ← مِنَامَن) · **الهمزتان في كلمة** (تحقيق الأولى وتسهيل/إبدال الثانية) |
| **الإمالة** | لا تقليل | **تقليل ذوات الياء** (ٱلْهُدَى، مُوسَى، تَقْوَى) و**ذوات الراء** (ٱلنَّارِ، ٱلدَّارِ)، ويُفتح ما كان من نحو: إِلَى، عَلَى، حَتَّى، لَدَى، ٱلرِّبَا |

وتُفحص فروق ورش **على المصحف كاملًا** في اختبار آلي مستقلّ (٧٧٨٨١ كلمة): ١٨٦٢ موضعًا
للنَّقْل، و١٠٦٨ لإبدال الهمز الساكن، و٦٧ للهمزتين في كلمة، و١٣٥٧ لتقليل ذوات الياء،
و٢٢٠ لتقليل ذوات الراء — بلا زمنٍ واحد غير صالح.

> الرسم المعروض هو الرسم العثماني نفسه في الروايتين؛ والفروق المُقاسة هي فروق **الأداء**
> (المدود والهمز والإمالة) لا فروق الرسم.

### حدود معروفة (باختيارٍ حكيمٍ)

- **إدغام التنوين الجاري** في نحو «غَيْرِ الْمَغْضُوبِ» و«مُلْكِ النَّاسِ»: يُرسم التنوين محذوفًا
  والياء محذوفة؛ لا يكشفه المحرِّك (لا قائمة بيضاء خاصة حتى لا تُساء تسمية «بِاللّٰهِ» و«لِلَّهِ»).
- **عَدَدَۢا**: تنوين على الدال بلا حرف تنوين مكتوب — تُقرأ الآية صحيحة حفصيًّا لكن القلقلة
  الكبرى فيها تناقش حالةً حرفية فائقة الدقة؛ التطبيق لا يعلّمها.
- **استدراكٌ موثَّق:** غُنّة النون والميم المشدَّدتين (ومنهما نون «ٱلنَّفَّاثَاتِ» في سورة الفلق)
  حكمٌ **متَّفقٌ عليه عند جميع القراء**، لا خاصّةً بحفص — وقد صُحّحت صياغة الشرح في التطبيق،
  وثُبِّتت باختبار على الآية نفسها.
- فروق ورش مُغطّاةٌ في **المدود والهمز والإمالة** على ما بُيّن أعلاه؛ وما عدا ذلك (مثل تحريرات
  مدّ اللين المهموز، وتغليظ اللام في بعض الألفاظ) لا يُقاس تلقائيًّا بل يبقى للتلقّي عن شيخ.
- التقييم الصوتي **مبدئي تعليمي**: يقيس أزمنة الأصوات ويقارنها بالأزمنة المقررة، لا يحاكي
  خبرة أستاذ التجويد في مهمة المخارج والصفات؛ هو رفيق تدريب، وليس بديلًا عن الإجازة.

## للمطوّرين

### التشغيل محليًا

```bash
npm install            # التبعيات
npm run dev            # التطوير http://localhost:3000
npm run test:rules     # اختبارات محرك الأحكام (وحدة + تغطية المصحف كاملًا + إحصاء)
npm run build          # بناء الإنتاج
npm run data           # (اختياري) إعادة توليد بيانات المصحف من AlQuran Cloud
```

> ملاحظة: إذا تعذّر تثبيت `onnxruntime-node` (ثنائيّات لغير المتصفح)، فالويب لا يحتاجها؛
> استخدم `npm install --ignore-scripts`.

### المعمارية باختصار

- **الروايتان:** `src/lib/tajweed.ts` يحلّل الرسم العثماني نفسه ثم يُطبِّق أصول الرواية المختارة
  (`Riwayah = 'hafs' | 'warsh'`) في المدود والهمز والإمالة، ولكل حكم شرحٌ تعليمي (`note`).
- **الخطوط:** لا تُحمَّل أي خطوط من الشبكة؛ مجموعات `font-quran`/`font-sans` في
  `tailwind.config.ts` تعتمد خطوط الجهاز مرتَّبةً بالبدائل، فالتطبيق يعمل بخطوطه بلا إنترنت.
- **سلامة الأعداد:** كل مخرجات النموذج تُمرَّر على `toNumberArray()` قبل أي حساب، فلا يصل
  BigInt (من معرفات int64 في بعض نُسخ ONNX Runtime) إلى عملية حسابية — وهو إصلاح
  «Cannot convert a BigInt value to a number» على الجوّال.
- **صوت القارئ المرجعي:** `src/lib/reciter.ts` يبني روابط الآية (SSSAAA.mp3) لكل رواية مع
  بدائل يُجرَّب بعضها بعد بعض، ولا يُحمَّل شيء منها إلا بضغطةٍ من المستخدم.

- **Next.js 15 + React 18 + TypeScript** (RTL بالكامل)؛ حالة بـ Zustand.
- **التعرّف الصوتي:** Whisper عبر \@huggingface/transformers (WASM) — بثلاث طرق متدرّجة:
  تراصفٌ بمصفوفة الانتباه (أدقّ)، ثم توكنات التوقيت، ثم مطابقة نسخ-طاقة؛ والبديل الرابع
  (موجّه طاقة VAD) يعمل دائمًا بلا نموذج.
- **محرك الأحكام** (`src/lib/tajweed.ts`): تقطيعات واعية بالرسم العثماني (محارف/علامات)
  له محرك تقاسم الحروف والحركات والعلامات المصحفية، وبُنى قواعد على نماذج التحفة/الجزرية،
  مع ملاحظة تعليمية مبسَّطة مُلحقة بكل حكم (`note`).
- **بيانات القرآن:** AlQuran Cloud (`ar.quran-uthmani`) مع نسخة محلية للعمل دون اتصال.
- **تنظيف النص:** علامات غير مرئية (U+200A/U+2060) والتطويل الزخرفي وعلامات الوقف تُفصَل
  قبل التحليل حتى لا تتفتّت الكلمات.
